# SmartParkour 0.9.4 — Adaptive Takeoff

Minecraft Java 1.21.11 / Fabric.

- Short/adjacent targets: jump from the center instead of approaching the edge.
- Longer targets: proportional run-up limited to the current block.
- If the approach stalls for 5 ticks, jump rather than wait forever.
- Intermediate gray wool platforms can be detected even when adjacent to the starting platform.
- Keep target lock, rotation before movement, landing behavior, O/P controls, and saved settings.

**Note:** Source patch, not verified by Gradle or an in-game test.
