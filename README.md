# SmartParkour 0.10.9 — source

For Minecraft 1.21.11 / Fabric.

In CHEAT mode, automatic inactivity rescue, phase-timeout action restarts, missing-target warp recovery and intermediate-route recovery are bypassed. The teleport settles at 0.5 blocks above the target platform surface. Server position rejection or failed landing still disables automation rather than retrying indefinitely. Cautious and Balanced retain existing recovery logic.

This is a source archive; build and in-game behavior have not been verified.
