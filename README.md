# SmartParkour 0.8.4 (Fabric 1.21.11)

- **O**: toggle auto parkour on/off.
- **P**: open settings screen.
- Settings slider: landing delay 0–5000 ms, default 500 ms, 50 ms increments.
- Opening the screen releases simulated movement keys; parkour resumes after closing if still enabled.
- No teleportation. Short approach remains limited to the starting block.

Build with `gradle build` or your GitHub Actions workflow. This source package has not been compiled in this environment.
